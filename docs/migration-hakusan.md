# 白山クラブの移行手順（Phase 6）

汎用版が動いてから実施する運用作業のチェックリスト。**旧システムと併存させない。**

---

## 1. 新しいスプレッドシートを用意する

- [ ] テンプレをコピーして「白山ラージボール卓球クラブ 出欠」を作る
- [ ] メニュー「出欠システム → 初期設定」を実行
- [ ] 「設定」B1 に `白山ラージボール卓球クラブ`
- [ ] 「出欠システム → 書き込みキーを作り直す」でキーを自分用に振り直す
- [ ] デプロイ（ウェブアプリ／実行：自分／アクセス：全員）→ `…/exec` を控える

## 2. データを移す

- [ ] 旧「性別管理シート」の19名 → 新「名簿」へコピペ（**A=名前 B=性別でそのまま合う**）
- [ ] 旧「大会マスタ（出欠連携）」の締切前の行 → 新「イベント」へ
      - イベントIDは手で採番してA列に入れる（他と重複しなければ何でもよい。例 `ev-hakusan-01`）
      - 種目は「、」区切り、要項リンクは任意
- [ ] 過去の回答は移さない（集計のやり直しはしない）

**引き継がないもの**
- LINEログインによる本人自動識別（whoami）。19名分の userId 紐付けは捨てる
  → メンバーには最初に1度だけ名前を選び直してもらう
- LIFF、要項PDFのiframe表示（要項はリンクのみ）

## 3. ドロッパーを新しい方に向ける

> ⚠ **旧 `?club=hakusan` の CLUB_MODE は dropper-app 側で撤去済み。**
> あの変更が公開された時点で、旧システムは新しい大会を受け取れなくなる。
> **この手順はドロッパーの公開と同時か、先に済ませること。**

- [ ] イベントドロッパーで要項を1枚ドロップし、カードの「🙋 出欠の回答フォームを付ける」を押す
- [ ] 設定モーダルに、新しいGASのURL（`…/exec`）と書き込みキーを入れて「保存して確認」
      → 「✓ つながりました：白山ラージボール卓球クラブ」と出れば完了（登録は1回だけ）
- [ ] 続けて「🙋 出欠を作る」→ 案内文に出欠リンクが入るか確認
- [ ] 旧 `?club=hakusan` のブックマークがあれば消す（`?club` を付けても何も起きなくなった）

## 4. L Message のリッチメニューを差し替える

| エリア | 差し替え先 |
|---|---|
| 1「わたしの回答」 | `…/attend/my.html?s={デプロイID}` |
| 2「出欠入力」 | `…/attend/?s={デプロイID}`（一覧モード） |
| 3「出欠確認」 | `…/attend/status.html?s={デプロイID}` |
| 4「カレンダー」 | 変更なし |

- [ ] 端末を替えた人・機種変更した人は、また名前を選び直すことになる旨も一言

- [ ] 旧マスタシートは消さずに残す（過去の記録として）
