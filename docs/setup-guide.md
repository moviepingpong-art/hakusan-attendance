# 主催者のセットアップ手順

出欠ドロッパーを、ある団体で使い始めるまでの手順です。**スマホだけで完結します。**
Googleアカウントも、表の用意も、アプリの登録も要りません。

> 旧GAS版（表をコピー → Apps Script → デプロイ → 承認 → URLを貼る）の手順書は、
> このファイルの git 履歴に残っています。載せ替えの経緯は [`backend-plan.md`](backend-plan.md)。

---

## 1. 団体をつくる（3分）

[app.dropper-tools.com/attend/admin.html](https://app.dropper-tools.com/attend/admin.html) を開きます。

- [ ] 団体名を入れる（例：`白山ラージボール卓球クラブ`）
- [ ] メンバーのお名前と男女を入れる。足りなければ「＋ 1人ふやす」
- [ ] 「この内容でつくる」

**男女は集計を男女別に出すために使います。**空のままでも構いません（「不明」に数えられます）。

## 2. 管理リンクを保存する（重要）

つくった直後に **管理リンク**が1回だけ表示されます。

> ⚠ **この画面を閉じると二度と表示できません。なくすと元に戻せません。**
> ブックマークに入れるか、自分あてにLINEやメールで送っておいてください。

このリンクがあなたの合鍵です。**人に渡さないでください。** 渡すと名簿も回答も操作されます。

合鍵は `#` のうしろに入っています。`#` のうしろはサーバーに送られないので、
アクセスログにも Referer にも残りません。

## 3. 配るURLを3本コピーする

管理画面の「みなさんに配るURL」から3本コピーします。

| | 中身 |
|---|---|
| ① 出欠を入力する | 受付中の行事が一覧で出る → 選ぶ → 回答 |
| ② わたしの回答 | 自分が何を答えたかの一覧 |
| ③ 集まり具合 | 人数の集計（男女別。個人名は出ません） |

**この3本はずっと変わりません。** 行事が増えても貼り直しは不要です。
LINE公式アカウントのリッチメニューに貼るのがおすすめです（手順は [`hakusan-setup.md`](hakusan-setup.md)）。

## ふだんの使い方

### はじめに1回：この端末に覚えさせる

管理画面の **「この端末に覚える」** を押しておくと、イベントドロッパーの
「🙋 出欠システムに保存」から**そのまま取り込めるようになります**。

> ⚠ **覚えた端末を使える人は、あなたと同じ操作ができます。** 共用のパソコンでは覚えさせないでください。
> また、**覚えていても管理リンクの控えは必ず別に残してください。**
> iPhoneのSafariは、しばらく使わないと端末の記憶を捨てます。

### 行事を取り込む

**イベントドロッパーを使う場合**

1. [イベントドロッパー](https://app.dropper-tools.com/calendar/)で要項（PDF・画像）をドロップ
2. カードの **「🙋 出欠システムに保存」** を押す
3. 管理画面が開いて、**取り込みまで済んでいます**

覚えさせていない端末では、届いた行事を**1時間だけ預かって**待ちます。
ご自分の管理リンクを開けば、そこで取り込まれます（貼り直しは要りません）。

**ドロッパーを使わない場合**

管理画面の **「＋ 手で入力して追加」** から、行事名・開催日・締切・会場・種目を入れます。

> 同じ行事名・同じ開催日は二重に取り込まれません。二度押しても増えないので安心してください。

### 出欠を作る

取り込むと、開催日・締切・種目が出ます。**内容を確かめて「この内容で出欠を受け付ける」** を押すと、
参加者の一覧に出ます。カードのバッジが「未使用」から「✓ 出欠あり」に変わります。

**押さずに閉じても構いません。** 行事は貯まっているので、使いたくなったときに
一覧の「この行事で出欠を作る」から始められます。

済んだら、画面の上の **「← イベントドロッパーに戻る」** で元の画面に戻れます
（案内文を作るのはそのあとです）。

> ここを自動にしていないのは、**読み違えた締切のまま受付が始まると直せない**ためです
> （消して作り直すことになります）。カレンダーに入れたいだけの回もあります。

### 集まり具合を見る

管理画面の「出欠の集まり具合」に、男女別の集計と**まだ答えていない方のお名前**が出ます。

> 未回答者の名前が出るのはこの画面だけです。参加者には人数しか見えません。

### 締め切る・開け直す

- **受付を締め切る** … 締切日より前に手じまいしたいとき
- **受付を再開する** … 手じまいを取り消すとき

締切日をすぎたものは自動で受付が終わり、参加者の一覧からも消えます（再開はできません）。

### 消す

- **この出欠を消す** … 集まった回答も一緒に消えます。元の行事は「未使用」に戻るので作り直せます
- **この行事を消す** … 出欠を作っていない行事だけ消せます
- **この団体を削除する** … 名簿・行事・出欠・回答がすべて消えます。元に戻せません

## 参加者から見えるもの

1. リッチメニューの「出欠入力」（＝配るURL①）を押す
2. **最初の1回だけ**、名簿から自分の名前を選ぶ
3. 受付中の行事が一覧で出る → 選ぶ
4. 要項・地図・カレンダー追加のボタンと、種目ごとの〇△×
5. 送信

答え直しは何度でもできます（締切まで）。回答は上書きせず追記されるので、履歴が残ります。

## よくあるつまずき

**「いま受付中のイベントはありません」と出る**
出欠を作っていないか、手じまいしているか、締切日をすぎています。
管理画面の「出欠の集まり具合」でバッジを確かめてください。

**回答画面に「要項を見る」が出ない**
要項のファイルがドライブに上がっていません。ドロッパーで「🙋 出欠システムに保存」を押すときに
Googleにログインしていると、そのとき上がります（カレンダーに登録するかどうかは関係ありません）。
ログインせずに取り込んだ場合は、行事ごと消して読み直してください。

**回答画面に地図ボタンが出ない**
その行事に会場が入っていません。手入力の行事なら会場欄を埋めて作り直してください。
2026年8月より前に作った出欠にも入っていません（当時その項目が無かったため）。

**ホーム画面のアイコンから使うと、覚えさせたはずなのに「団体をつくる」に戻る**
**ホーム画面に登録したアプリは、ブラウザとは別のものとして扱われます。**
Safariで覚えさせたことは、そちらには引き継がれません（Googleのログインも同じです）。
ホーム画面のアイコンから開いて、**その中でもう一度「この端末に覚える」を押してください。**
一度押せば、以降はその中で完結します。

**参加者が「名前を選んでください」に戻ってしまう**
端末の記憶はアドレスの出どころごとに別物です。配るURLを
`app.dropper-tools.com` に統一してください。ブラウザの履歴やサイトデータを消した場合も戻ります。

**管理リンクをなくした**
復旧できません。団体を作り直すことになります。**保存を強くおすすめします。**

## 開発者向け

APIとデータの構造は [`api/README.md`](../api/README.md) と [`api/schema.sql`](../api/schema.sql) を参照。

- 回答と紐付けは**追記式。集計は最新行を採用**。`UPDATE` を書きたくなったら立ち止まること
- 集計に個人名を入れてよいのは `tally` と `adminEvents` だけ。参加者に見える `summary` には入れない
- 日付は中では `YYYY-MM-DD`、外に出すときは `YYYY/MM/DD（曜）`。
  参加者ページの「あと2日」表示がスラッシュ区切りを前提にしている
