# 白山クラブの立ち上げ手順

**白山クラブは旧システムを一度も使っていない。** そのため移行作業（データの引き継ぎ、旧システムの停止、
メンバーへの「選び直し」の周知）は不要で、ふつうに新規セットアップするだけでよい。

作業はすべて **PCのブラウザ**で行うこと。Apps Script のデプロイ画面はスマホだと操作しづらい。

---

## 0. 先に決めておくこと

**どのアドレスを使うか。** 出欠ページは
[app.dropper-tools.com/attend/](https://app.dropper-tools.com/attend/) を使う。

> ⚠ **出どころ（オリジン）を混ぜないこと。**
> 出欠ページは端末IDをブラウザに記憶させて本人を判別している。この記憶は**アドレスの出どころごとに別物**で、
> `app.dropper-tools.com` と `moviepingpong-art.github.io` を混ぜると、回答する人がもう一度名前を選ぶことになる。
> イベントドロッパーが案内文に入れるリンクは `app.dropper-tools.com` なので、**3本のURLもそちらで統一する。**

---

## 1. スプレッドシートを作る

- [ ] [セットアップ](https://app.dropper-tools.com/attend/setup.html)を開き、テンプレートをコピー
      （テンプレ未作成なら [setup-guide.md](setup-guide.md) の「A」を先に）
- [ ] コピーした表を開き、メニュー **「出欠システム → セットアップを開く」**

ここから先は、表の中の画面が順番に案内する。

- [ ] 団体名に `白山ラージボール卓球クラブ`
- [ ] **人数に 19 と入れて「入力欄を作る」** → 19人分の欄にお名前と男女を入れて保存
      - 旧「性別管理シート」を見ながら打つ。表記ゆれは気にしなくてよい
        （「山田 太郎」「山田太郎」は同じ人として扱われる）
      - 同姓同名がいると画面が止める。「山田太郎（父）」のように区別できる書き方にする
- [ ] 図解のとおりデプロイ（ウェブアプリ／実行：**自分**／アクセス：**全員**）
- [ ] URLを貼って「確かめて保存する」→ 3本のURLと書き込みキーが出る

**「このアプリは確認されていません」**は、自分で書いたスクリプトを自分で承認するだけ。
「詳細」→「（プロジェクト名）に移動」→「許可」と進む。

## 2. あとから名簿を直したくなったら

- [ ] メニュー「出欠システム → セットアップを開く」→「もどる」でメンバーの画面へ
- [ ] やめた人は「名簿」シートの備考に「退会」と書いても選択肢から消える（過去の回答は残る）

## 3. イベントドロッパーとつなぐ

- [ ] [イベントドロッパー](https://app.dropper-tools.com/calendar/)で要項を1枚ドロップ
- [ ] カードの「🙋 出欠の回答フォームを付ける」を押す
- [ ] 設定モーダルに `…/exec` のURLと書き込みキーを入れて「保存して確認」
      → 「✓ つながりました：白山ラージボール卓球クラブ」（登録はこの1回だけ）
- [ ] 続けて「🙋 出欠を作る」→ 案内文に出欠リンクが入るか確認

## 4. L Message のリッチメニュー

| エリア | 差し替え先 |
|---|---|
| 1「わたしの回答」 | `https://app.dropper-tools.com/attend/my.html?s={デプロイID}` |
| 2「出欠入力」 | `https://app.dropper-tools.com/attend/?s={デプロイID}`（一覧モード） |
| 3「出欠確認」 | `https://app.dropper-tools.com/attend/status.html?s={デプロイID}` |
| 4「カレンダー」 | 変更なし |

## 5. 動作確認（自分のスマホで）

- [ ] 案内文の出欠リンクをLINEに貼り、**青下線・タップ可**になること（110字なので収まるはず）
- [ ] 開いて名前を選び、〇△×を送れること
- [ ] 送信後に集計（人数のみ）が出ること
- [ ] 「わたしの回答」に自分の回答が出ること
- [ ] スプレッドシートの「回答」シートに行が増えていること

## 6. メンバーへの周知

- [ ] 「最初に1度だけ、名簿からご自分のお名前を選んでください」
- [ ] 「LINEアプリの外（ふつうのブラウザ）でも開けます」
- [ ] 機種変更したら、また名前を選び直すことになる旨も一言

---

## 運用でおぼえておくこと

- **名簿はセットアップ画面から、イベントは「イベント」シートを直接。** 凝った管理画面は作っていない
  （次の代表がAIを使わなくても運用できることを優先した仕様）。
- **集計は「出欠システム → 集計を更新」**。未回答者の名前が出るのは、この「集計」シートだけ。
  参加者に見える画面には人数しか出ない。
- **再デプロイの鉄則**：デプロイ → **デプロイを管理** → 鉛筆 → バージョン「**新しいバージョン**」→ デプロイ。
  URLは変わらない。**「新しいデプロイ」を連発すると詰まる。**
- 出欠を作り損ねたときは、**ボタンをもう一度押すだけ**。要項を再ドロップしない
  （カレンダーの予定が重複する）。
