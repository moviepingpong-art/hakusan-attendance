# 白山クラブの立ち上げ手順

**白山クラブは旧システムを一度も運用していない。** そのため移行作業（データの引き継ぎ、
メンバーへの「選び直し」の周知）は不要で、新規に作るだけでよい。

作業は**スマホだけで完結する**。PCでもよい。

> 旧GAS版（表をコピー → Apps Script → デプロイ → 承認）の手順は git 履歴に残っている。
> 載せ替えの経緯は [`backend-plan.md`](backend-plan.md)。

---

## 0. 先に決めておくこと

**どのアドレスを使うか。** 出欠ページは
[app.dropper-tools.com/attend/](https://app.dropper-tools.com/attend/) を使う。

> ⚠ **出どころ（オリジン）を混ぜないこと。**
> 出欠ページは端末IDをブラウザに記憶させて本人を判別している。この記憶は**アドレスの出どころごとに別物**で、
> `app.dropper-tools.com` と `moviepingpong-art.github.io` を混ぜると、回答する人がもう一度名前を選ぶことになる。
> **配るURLは app.dropper-tools.com で統一する。**

---

## 1. 団体をつくる

- [ ] [管理画面](https://app.dropper-tools.com/attend/admin.html)を開く
- [ ] 団体名に `白山ラージボール卓球クラブ`
- [ ] メンバー19人のお名前と男女を入れる（「＋ 1人ふやす」で足す）
      - 旧「性別管理シート」を見ながら打つ。表記ゆれは気にしなくてよい
        （「山田 太郎」「山田太郎」は同じ人として扱われる）
      - 同姓同名がいると画面が止める。「山田太郎（父）」のように区別できる書き方にする
- [ ] 「この内容でつくる」

## 2. 管理リンクを保存する

> ⚠ **1回しか表示されない。なくすと元に戻せない。**

- [ ] ブックマークに入れる
- [ ] さらに自分あてにLINEで送っておく（端末を替えても拾えるように）
- [ ] **人に渡さない。** 渡すと名簿も回答も操作される

## 3. あとから名簿を直したくなったら

- [ ] 管理リンクを開き、「団体名とメンバー」で直して「保存する」
- [ ] やめた人は**備考に「退会」**と書けば選択肢から消える（過去の回答は残る）

## 4. イベントドロッパーとつなぐ

- [ ] 管理画面の **「この端末に覚える」** を押しておく（ここを飛ばすと、届いた行事を預かるだけになる）
- [ ] [イベントドロッパー](https://app.dropper-tools.com/calendar/)で要項を1枚ドロップ
- [ ] カードの **「🙋 出欠システムに保存」** を押す
- [ ] 管理画面が開き、取り込みまで済んでいることを確かめる
- [ ] 開催日・締切・種目を見て **「この内容で出欠を受け付ける」**

ドロッパー側に設定は無い。覚えるのは管理画面のほうなので、機種を替えたら
**新しい端末で管理リンクを開いて、もう一度「この端末に覚える」を押す**。

> ⚠ 覚えた端末を使える人は主催者と同じ操作ができる。共用のPCでは覚えさせない。
> **覚えていても、管理リンクの控えは必ず別に残しておくこと。**

## 5. L Message のリッチメニュー

`{団体ID}` は管理画面の「みなさんに配るURL」からコピーする。**この3本はずっと変わらない。**

| エリア | 差し替え先 |
|---|---|
| 1「わたしの回答」 | `https://app.dropper-tools.com/attend/my.html?s={団体ID}` |
| 2「出欠入力」 | `https://app.dropper-tools.com/attend/?s={団体ID}`（一覧） |
| 3「出欠確認」 | `https://app.dropper-tools.com/attend/status.html?s={団体ID}` |
| 4「カレンダー」 | 変更なし |

> **管理リンクはリッチメニューに貼らないこと。** 全員が主催者になってしまう。

## 6. 動作確認（自分のスマホで）

- [ ] リッチメニュー「出欠入力」→ 名前を選ぶ → 行事を選ぶ → 〇△×を送れること
- [ ] 回答画面に「要項を見る」「地図で見る」「カレンダーに追加」が出ること
- [ ] 送信後に集計（人数のみ）が出ること
- [ ] 「わたしの回答」に自分の回答が出ること
- [ ] 管理画面の「出欠の集まり具合」に、自分が回答者として数えられていること
- [ ] 案内文に**URLが1本も入っていない**こと（末尾の出欠の1行だけ）

## 7. メンバーへの周知

- [ ] 「最初に1度だけ、名簿からご自分のお名前を選んでください」
- [ ] 「下のメニューの『出欠入力』から答えられます」
- [ ] 「LINEアプリの外（ふつうのブラウザ）でも開けます」
- [ ] 機種変更したら、また名前を選び直すことになる旨も一言
